#### 使用

1. 在 ALB 看板的“实例”页面，点击“创建后端服务器组”
	1. 选择服务器类型
	2. 名称
	3. 选择 ALB 对应的 vpc
	4. 选择后端协议
	   根据实际需求
		1. HTTP
		2. HTTPS
		3. gRPC
	5. 调度算法
	   根据实际需求
		1. [加权轮询](调度算法-加权轮询) 
		2. [加权最小连接数](调度算法-加权最小连接数)
		3. [一致性哈希](调度算法-一致性哈希)
	6. 选择资源组
	7. 开启健康检查
		1. 设置健康检查端口
		   依靠这个端口去检查，返回状态码
		2. 设置健康状态返回码
		3. 响应超时时间、间隔时间、健康阈值、不健康阈值
2. 在服务器组中“添加后端服务器”
	1. 选择 ECS/弹性容器
	2. 填写端口和权重
3. “实例”看板 - 监听
	1. 点击 ALB 实例，配置监听（创建监听）
		1. 选择负载均衡协议、监听端口、名称、高级配置
		2. 选择服务器类型
			1. 服务器类型
			2. IP 类型（ECI）
			3. 函数计算类型
		3. 选择服务器组
		4. 提交
	2. 设置域名解析
	   （ALB 支持将拥有的域名通过 CNAME 方式解析到 ALB 实例的公网服务器域名上）
	3. 查看/编辑转发规则（可选）
