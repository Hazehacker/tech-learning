


## 效率 = SQL 执行效率

具体指：

| 阶段         | 影响                             |
| ------------ | -------------------------------- |
| **磁盘 I/O** | 扫描更多数据页，物理读取次数增加 |
| **内存占用** | 临时表、排序缓冲区占用更多内存   |
| **CPU 计算** | 更多行参与 JOIN 匹配、过滤、排序 |
| **网络传输** | 返回更多数据行到应用层           |

---

## 负载 = 数据库服务器整体压力

不仅仅是 CPU，还包括：

| 资源         | 受影响情况                                |
| ------------ | ----------------------------------------- |
| **CPU**      | JOIN 匹配、过滤、排序计算                 |
| **内存**     | 临时表、排序缓冲区、连接缓冲区            |
| **磁盘 I/O** | 读取更多数据页到缓冲池                    |
| **锁竞争**   | 大范围扫描可能触发表锁/行锁，阻塞其他查询 |
